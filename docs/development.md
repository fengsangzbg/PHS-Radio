# 开发与构建说明

当前开发版本 v0.2.3 beta 只开放酷狗，使用 PHSRADIO_KUGOU_ONLY=ON 构建。关闭该选项会启用未开放平台的开发代码；这不代表发布版已支持这些平台。

## 模块

- main.cpp 管理窗口、页面、账号、搜索与播放控制。
- MusicProvider 隔离平台接口；酷狗客户端处理扫码登录、歌单、分页、曲库搜索、推荐、音源与歌词。
- MusicSearch 管理文本、别名、简繁体与拼音索引；PlaybackQueue 管理顺序、随机与历史队列。
- AeroWidgets 负责玻璃外观、Dock、滑出歌单、卡片、时钟、唱片及流星动画。
- SmoothScrollController 对滚轮采用随时间收敛的像素滚动，并在同一次帧回调内更新 SongGlassDelegate 的果冻状态；触控板保留系统提供的像素和惯性。用户拖动滚动条、键盘定位、重建模型与隐藏窗口会停止旧滚动目标。
- Dock 音量与静音仅绑定音乐的 QAudioOutput；设置写入合并到操作结束后，退出时保存未完成的音量更改。不使用系统主音量控制接口。
- AeroSurface 按屏幕实际像素绘制背景并共享模糊纹理；WallpaperEngineCapture 只创建、捕获和关闭软件自己的动态壁纸窗口。
- CoverImages 用两个后台工作线程解码、缩放封面；高清原图优先于列表缩略图，完成后回到界面线程更新。队列数量与编码字节数有上限。
- LatestVideoFrame 在线程安全的单帧缓冲中保留最新视频／抓帧画面。WE 的 parentless QVideoSink 先在 GUI 绑定 session，再移入独立接帧线程，避免上游逐帧 GUI 队列；回调直接替换旧帧，只持有缓冲共享所有权，不访问控件。停源后排空接帧线程，销毁前把 sink 移回 GUI、解绑和删除。
- VideoFrames 对通过格式、色彩及方向检查的普通 32 位 RGB 帧直接映射并复制出独立 QImage，避免 Qt 通用转换中的额外纹理上传与读回。`canConvertRgb` 只检查元数据；`toRgbImage` 只做直接转换，格式不兼容或映射失败返回空图，适合安全的工作线程路径。YUV、HDR、硬件纹理等不匹配帧由界面线程调用带 Qt 回退的 `toImage`，工作线程不创建 QRhi。
- WallpaperEngineCapture 的 RGB 转换只有一个在途任务、一个最新源帧和一个待显示结果。完成回调存储当前代次的结果，并用原子 `takeIf` 立即接下一张安全 RGB 帧；下一次显示 tick 才发布。暂停、换源、停止和渲染尺寸变化时清理结果并递增代次，拒绝旧任务回调；同尺寸守护不清帧。旧任务结束前不释放忙碌状态，避免快速恢复产生多个并行任务。任务独立持有源帧与 promise，不持有控件。
- AeroSurface 的动态模糊另有一个后台任务和一个最新待处理状态，不与抓帧转换共用队列。切换主题、改变尺寸、暂停与关闭时清理或拒绝过期结果。
- AppUpdater 从固定 GitHub 仓库读取正式版本、异步下载并核对 SHA256SUMS.txt 和附件摘要。程序内置的固定 PowerShell 安装器在检查通过后等待旧进程退出、备份替换文件、失败回滚并重启；不读取或修改账号设置。
- 本地 beta 版本可比较并升级至后续正式版本。远端仍仅接受正式 x.y.z Release，不自动安装预发布附件。

## Windows 工具链

发行构建使用 MSYS2 UCRT64、Qt 6.11.2、FFmpeg 9.0.2、ICU 78 和 Node.js 24.21.0；所需 DLL 由打包脚本检查并收集。

使用同一工具链的 C++17 编译器、Qt 与 ICU，按 README 构建。运行 npm ci --prefix services/kugou --omit=dev --ignore-scripts 安装锁定依赖。测试使用本地模拟数据和静音媒体，不需要真实平台账号；更新下载测试使用离线网络模拟。

MinGW 构建对新增 QObject 模块采用相对文件名调用 moc，避免该工具对中文绝对路径的编码错误。

tools/test-portable-update.ps1 可在工作区创建两份便携包副本，验证中文空格路径的完整更新、校验失败、只读文件、失败回滚和用户文件保留。运行 -RunSmoke 还会检查更新后真实 EXE 的原生插件启动；不修改原始发布包和真实账号。

PHSRADIO_APP_OUTPUT_DIR 可设置独立 EXE 输出目录，以免预览窗口锁住需要重新链接的文件。打包时可传 -ExePath 明确选择发布EXE，脚本拒绝旧版本和未启用酷狗门控的配置。

性能验证与计时范围见 [流畅度说明](performance.md)。

## 便携包

打包工具只收集应用、运行库、锁定生产依赖和许可文档，不复制用户设置、运行缓存、调试日志、私人壁纸、音乐或开发构建目录。必须完整解压；不能只分发 EXE。

## 对应依赖源码

同版本 Release 提供第三方源码附件，包含与实际 MSYS2 包版本匹配的完整源码、PKGBUILD、补丁和 SHA256 清单。应用源码由同版本Git标签提供。可用兼容动态库替换随包 DLL；未设置安装锁定或签名校验限制。
