PHS Radio新大地播放器 v0.3.0 正式版 / Windows x64

本次更新
- 新增网易云二维码登录，与酷狗独立保存账号、同时登录。
- 新增网易云创建、收藏及红心歌单，按完整歌曲 ID 分页获取歌曲；失败可重试。
- 左侧歌单栏可切换网易云／酷狗，切换浏览时保持当前播放。
- “猜你想找”搜索已登录的两个平台，显示各自标识，独立分页与重试。
- 播放 Dock 新增标准／高品质／无损音质选择，两个平台分别记忆。
- 音质切换获取地址失败时保留原播放；正常切换保留进度和暂停状态。
- 保留液态玻璃、歌词、高清封面、独立音量和 Wallpaper Engine 背景。

已知问题
网易云登录、歌单和搜索已实测，但播放仍可能对全部歌曲返回空音源，尚未解决。
本版不保证网易云歌曲可以播放，也不将此问题一概归因于会员或版权。
网易云音质参数已接入，但实际试听仍受此问题影响。酷狗音源及音质取决于平台与账号权限。
AeroPod 启动特效暂未接入。

使用与更新
请完整解压并运行 PHSRadio.exe，保留 services、runtime、DLL 和插件目录。
“平台连接”中扫码登录；左侧切换账号歌单；播放 Dock 点击“音质”选择优先音质。
账号凭据由当前 Windows 用户的 DPAPI 分别加密保存，不随运行包发布。
旧版可在“更新”中检测 v0.3.0 正式版，也可手动完整解压到新目录运行。
登录与主题设置保留。Wallpaper Engine 背景固定静音，不包含 WE 本体及用户壁纸。
