修复歌曲列表滚轮卡顿：滚动与果冻晃动合并更新，缓存高清文字与背景采样，缩短拖尾；保留卡片弹性、反射高光与透出动态壁纸的玻璃效果。
动态毛玻璃改为后台计算，保留原有模糊效果与高清壁纸；忙碌时合并中间帧，减少界面线程停顿。
优化玻璃模糊的像素访问，封面解码和缩略图缩放移到后台，优先加载当前歌曲的高清封面。
视频与 Wallpaper Engine 使用最新帧缓冲，减少繁忙时的旧帧堆积；壁纸继续静音，独立渲染窗口保持桌面透明。
Wallpaper Engine 接帧和安全 RGB 转换移出界面线程；修复非整数 DPI 下每帧重复缩放，按窗口物理像素直接共享原画面。暂停、换源与调整尺寸会隔离过期结果。
音乐库加载新歌曲或更新已有信息时复用列表条目，封面按行索引批量更新，减少大歌单刷新开销。
修复窗口还原后首页内容被截断的问题：每日推荐保留方形封面和完整文字，横向浏览全部推荐；首页随窗口尺寸调整，并支持纵向滚动。

启动软件
完整解压发布包，双击 PHSRadio.exe。请保留 DLL、Qt 插件、runtime、services 等全部文件；无需另装 Qt、Node.js 或 npm。
旧版用户先关闭播放器，将新完整包解压到一个新文件夹，再运行其中的 PHSRadio.exe。账号与主题设置仍保存在当前 Windows 用户下，无需额外下载或覆盖设备验证补丁。

酷狗与播放
使用手机酷狗 App 扫描软件内的二维码并确认登录。账号歌单和歌曲会在后台逐步加载；未加载完整时可在左侧歌单面板重试。
顶部搜索查询酷狗全平台曲库；歌单面板的搜索只筛选自己的歌单。双击歌曲播放，鼠标靠近底部展开 Dock，可固定、切歌、顺序或随机播放、拖动进度并调整音乐音量。
支持首页每日推荐、跟随电脑时区的时钟、同步滚动歌词和带高清封面的旋转玻璃唱片。
软件免费使用；音乐能否播放取决于酷狗接口返回的音源及账号权限。第三方接口与官方 App 的返回不一定一致，取得音源不代表歌曲没有会员或地区限制。

Wallpaper Engine 与多种风格
顶部“主题”可导入图片、GIF 或视频，自定义背景和遮暗程度；Dock 调色按钮可选择预设或自选颜色，搭配复古、明亮、水蓝、薄荷等多种风格。
支持导入已安装的 Wallpaper Engine 壁纸。视频直接循环播放；场景、网页壁纸需要本机安装并运行 Wallpaper Engine，以软件专属窗口输出动态背景。原工程和桌面壁纸设置不修改；Wallpaper Engine 本体与壁纸作品不随软件分发。
软件背景固定静音，音乐音量独立。窗口隐藏或失活时停止背景解码/抓帧；实际画质与帧率取决于源素材和电脑性能。
场景和网页壁纸的源帧率跟随 Wallpaper Engine 全局设置。在 WE“设置 → 性能”中调整并应用，会同时影响桌面和软件内该类壁纸；当前 Windows 捕获后端最高为 60 FPS，软件内实际帧率还受绘制开销影响。视频壁纸仍保持原视频帧率。

耳机与账号
播放器跟随 Windows 默认播放设备切换。3.5mm 插孔的自动切换同时取决于声卡驱动和 Windows 默认设备设置。
账号凭据由当前 Windows 用户的 DPAPI 加密保存。发布包不包含开发者账号、登录数据、私人壁纸或音乐文件。
