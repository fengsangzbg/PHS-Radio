PHS Radio新大地播放器 v0.3.1 正式版 / Windows x64

本次更新
- 新增 GPU 水族箱 MP3 启动界面：天空、游动鲸鱼、玻璃 MP3、旋转台风 P logo 与柔软按压反馈。
- 点击 logo 打开平台登录；登录后手动点击「完成登录」回到 MP3，再次点击 logo 经屏幕缩放和高清文字动画进入播放器。
- 过渡文字采用清晰的抗锯齿 UI 字体，逐字显示「新大地-今天想听点什么」。
- 主题弹窗升级为透明玻璃，默认水光更明亮清透，新增「火流星」夏夜夜空与流星雨。
- Dock 播放激光固定在右上至左下的方向，整条亮起后约一秒熄灭；增加亮芯与柔光层次，火流星主题同步切换暖色。
- 修复「更新」文字裁切，移除按钮交互虚线，提高倾斜按钮的贴图采样精度与边缘平滑度。
- 保留酷狗、网易云双平台登录、歌单、聚合搜索、歌词、音质选择、独立音量与 Wallpaper Engine 静音背景。
- 网易云播放已由用户实测确认恢复可用。

使用与更新
请完整解压并运行 PHSRadio.exe，保留 services、runtime、DLL 和插件目录。
旧版可通过标题栏「更新」获取 v0.3.1 正式版，或将完整包解压到新的可写目录运行。
账号和主题设置保留，账号凭据由当前 Windows 用户 DPAPI 加密，不随发行包发布。
音乐能否播放及实际音质取决于平台返回、账号权限与所在地区。
启动界面实际帧率受显示器、驱动与性能影响，不承诺所有设备达到同一帧率。
Wallpaper Engine 背景保持静音，不包含 WE 本体及用户私人壁纸。
