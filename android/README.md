# PHS Radio Android 0.3.0-preview

原生 Java 安卓工程，独立于 Windows C++/Qt 版本。Windows 入口、CMake 和 Wallpaper Engine 代码未改动。本包为手机测试版，不是 Windows 更新包。

## 当前界面

五页依次为：酷狗歌单、酷狗每日推荐、唱片与歌词、网易云每日推荐、网易云歌单。启动默认第三页；Dock「歌词」返回第三页并打开歌词视图。左右滑动切页，顶部也可点选。推荐卡片内部横向滚动、进度条和输入框不会触发切页。第三页没有时钟，默认用完整空间展示大唱片；Dock「歌词」切换到完整滚动歌词，支持返回唱片，不再把两块内容挤在一起。

顶部「搜索歌曲」合并本地导入歌曲、酷狗、网易云，标明来源，在线来源单独失败不会清空本地结果。当前在线搜索每个平台返回首批最多 50 首。歌单页点封面进入完整曲目页，内置当前歌单筛选；筛选后点击仍定位到原歌单队列。

## 账号、播放与歌词

- 两平台独立扫码登录，可同时保存。二维码本地生成，可保存相册用官方 App 扫码。凭据用 Android Keystore AES-GCM 加密，备份关闭，不读取 Windows 会话。
- 平台歌单分页读取，检测重复分页；网易云按完整 trackIds 分批取详情并保持原顺序，无法取得详情的歌曲保留占位。页面离开后取消后续批次。
- 在线曲目点播、每日推荐点播接入媒体前台服务。每首开始时按当前账号重新取音源，不批量缓存临时播放地址。酷狗独立完成设备注册；验证失效时清理设备标识以供重试。
- 顺序、随机、单曲循环，进度拖动、应用内音量、媒体通知、音频焦点和耳机断开暂停。大队列经应用缓存文件交接，避免把整张大歌单塞进 Binder。
- 网易云在线 LRC、酷狗按歌曲 hash 查询并下载 LRC、当前歌曲本地 UTF-8 LRC 导入、时间同步高亮和点击歌词定位。平台无歌词时可手动导入。
- 唱片暂停时停转，播放时旋转。优先平台封面／本地内嵌原图，解码最长边最高 2048 像素；没有封面使用 P 占位，不伪造高清图片。
- 只使用平台正常授权音源；会员、购买、地区和版权限制由平台决定，无替代音源或解锁逻辑。

## 视觉与背景

按钮统一玻璃高光、按压压缩与回弹。水光使用缓慢水纹反射，火流星使用稳定夜空和错峰暖色流星。播放触发多颗加速下落、弯曲长尾、亮头与碎光；主题切换为水色／火色，播放流星可关闭。动画使用帧同步回调，离开应用暂停；未在手机测量保证帧率。

玻璃为原生渐变、透明高光和曲线绘制，尚无实时背景光学折射。系统动态壁纸通过 FLAG_SHOW_WALLPAPER 显示：先在星空视频壁纸中设置桌面壁纸，再在主题菜单开启。系统壁纸声音归壁纸 App 管理；本软件导入的视频始终静音。支持系统文件选择器与分享导入图片／视频，不读取星空私有目录。

## 验证范围

已通过 APK 编译和签名检查。使用实际 OnlineApi 类的主机测试覆盖网易云整张 401 首歌单分批读取、曲目规范化、搜索分页、授权 URL、不可播音源拒绝和五页手势边界。火流星运动模型通过 120Hz 连续性和长时间精度测试。

实际安卓协议代码已联网验证酷狗公开搜索（返回 50 首）、推荐歌单和匿名设备注册；匿名音源请求未获可播地址。上述匿名测试不代表真实账号播放验证。未连接小米设备，真实扫码、账号歌单、账号在线播放、音频解码、手势与画面效果需要真机验收。

手机验收顺序：覆盖安装 → 两平台扫码 → 两侧歌单封面进入曲目页 → 筛选点播 → 上下首、随机、单曲循环 → 第三页封面和歌词 → 两平台每日推荐 → 全局搜索 → 后台、耳机、静音壁纸。

## 构建

Android 9+，API 35，Java 17 字节码，无 Node、Qt、NDK 或本机 .so。Android Studio 使用 AGP 8.9.2 / Gradle 8.11.1 / JDK 17；独立构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/prepare-sdk.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-preview.ps1
```

输出：`app/build/outputs/apk/preview/PHS-Radio-Android-0.3.0-preview.apk`。本地测试签名可覆盖前期预览包；密钥和 SDK 留在 `.toolchain`，不可公开发布测试签名密钥。正式发行需单独规划长期签名和更新渠道。

遵循上级 GPL-3.0；二维码库 ZXing Core 3.5.3 使用 Apache-2.0，许可证见 app/libs/ZXing-LICENSE.txt。平台协议参考现有 Windows 依赖 MakcRe/KuGouMusicApi、NeteaseCloudMusicApiEnhanced。主机测试 JSON 库只放 `.host-test`，不进入 APK。

## 0.1.5 修复说明

紧凑 Dock 保留播放控制，高度约减半，贴底摆放；进度放在底部，应用音乐音量改为侧边竖向控件。歌单渐进显示、取消和短时完整缓存已接入。歌曲缺少 hash 时尝试有效音频 ID，真正缺标识的行保留并标注，不再中断整张歌单。

歌词现在独立取回，显示真实加载／错误状态；修复了酷狗签名和客户端头导致的空响应，支持完整滚动与重试。封面补查接口已接入，列表缩略图和唱片分别按 512／2048 目标解码。

网易云二维码请求保留 Cookie、固定安装设备身份，重试不会因一次网络异常中断；回前台立即检查，可手动检查，成功前校验账号、成功后刷新页面。真实授权确认仍待手机验收。

额外回归涵盖 LRC 偏移、多时间戳、纯文本、KRC 解码、嵌套字段、仅音频 ID、缺标识保留、扫码 Cookie 合并和嵌套状态。实际联网验证新二维码返回等待扫码 801，以及酷狗逐句歌词、封面和公开歌单首批识别。
## 0.3.0 启动场景

- 新增水族箱启动界面：天空照片、缓慢游过的座头鲸、玻璃地面上的焦散光带、上升气泡与暗角，全部用 Canvas 逐帧绘制，不依赖 OpenGL。
- 中央玻璃卡片使用与 Windows 同一份矢量源生成的 1024px 高清 logo；标题、副标题与「点击进入」呼吸提示都放在卡片内。
- 点击卡片后卡片轻微放大并淡出，随后移除该视图，露出播放器界面。
- 顶部标题栏的 logo 也从低清矢量换成同一张高清位图，两端图形统一。
- 两张照片按屏幕宽度采样解码（天空上限 1620px），避免低内存机型一次性占用十几 MB 堆。
