PHS Radio Android 0.2.0-preview

- 唱片重做为 Aero 清透玻璃：淡青玻璃盘体（左上受光）、20 圈冷色细纹、四段色散边弧、
  双层亮边；封面先铺不透明底再贴，外加 2.2dp 白色亮框，封面清晰不透。
  玻璃高光只覆盖封面外的环带，另加两道白色镜面反光弧。
- 新增收藏：Dock 标题右侧的 ♡ 按钮，点击收藏到「我喜欢的音乐」（本地保存），
  再点取消；点亮时浮出一颗水晶爱心，12 道彩虹光向外扩散并淡出。
- 新增分享：标题右侧「分享」，把「歌名 - 歌手 + 平台链接」交给系统分享面板，
  QQ / 微信可直接发送，朋友点开链接跳转网易云或酷狗对应页面。
- 新增音质：进度条右侧「音质·标准」按钮，循环切换 标准 / 高品质 / 无损，
  值传给本机 API 的 quality 参数（128 / 320 / flac），下一首生效。
